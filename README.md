# AntiMAX-Cannon

> *«Восстаньте, вам нечего терять, кроме ваших заборов из колючей проволоки!»*
> — Тимоти Мэй, «Манифест криптоанархиста»

AntiMAX-Cannon — инструмент для засорения аналитических серверов AppTracer (используется в некоторых мессенджерах для скрытой записи звонков). Работает по принципу «шум вместо сигнала».

## Как это работает

1. Получает `uploadToken` через `initUpload` (двухэтапная аутентификация)
2. Шлёт мусорный файл (raw PCM) на `upload`
3. Повторяет в N потоков до бесконечности или до квоты
4. При достижении квоты автоматически засыпает на указанное сервером время и продолжает

## Установка

```bash
git clone https://github.com/post-hum/AntiMAX-Cannon.git
cd AntiMAX-Cannon
pip install requests
```

## Использование

```bash
# Базовый запуск (20 потоков)
python3 antimax_cannon.py

# Агрессивный режим, 100 потоков
python3 antimax_cannon.py --threads 100 --aggressive

# С ротацией прокси
python3 antimax_cannon.py --proxy-list proxies.txt

# Флудить 1 час
python3 antimax_cannon.py --duration 3600

# Другой feature (обход квоты)
python3 antimax_cannon.py --feature PERFORMANCE_METRICS

# Полный дебаг
python3 antimax_cannon.py --debug --verbose
```

## Параметры

| Флаг | Описание |
|------|----------|
| `-t, --threads` | Количество потоков (default: 20) |
| `-d, --duration` | Длительность в секундах (0 = бесконечно) |
| `-s, --size` | Размер мусорного файла в байтах (default: 1.9MB) |
| `-i, --interval` | Задержка между запросами (default: 1.0) |
| `-a, --aggressive` | Агрессивный режим (без задержек) |
| `--feature` | Feature name (default: SAMPLED_TRACE) |
| `--token` | SampleToken (по умолчанию встроен) |
| `--proxy` | HTTP/SOCKS прокси |
| `--proxy-list` | Файл со списком прокси (ротация) |
| `--random-ua` | Случайный User-Agent |
| `--debug` | Полный вывод запросов и ответов |
| `-v, --verbose` | Подробный вывод |
| `-q, --quiet` | Только финальная статистика |

## Результаты

При тестировании с 20 потоками было отправлено **430 запросов (~900 MB)**, после чего сервер вернул `QUOTA`:

```json
{"errorCode":"QUOTA","code":7,"message":"Quota for daily application sample count exhausted","commands":{"featureShutdownMs":86400000}}
```

Скрипт автоматически обрабатывает квоту, засыпает на указанное время и продолжает.

## QUOTA handling

Сервер AppTracer имеет квоту на количество `initUpload` запросов в день. AntiMAX-Cannon:

- Распознаёт `QUOTA` в ответе
- Извлекает `featureShutdownMs` (время блокировки)
- Засыпает на это время
- После пробуждения продолжает флудить

## Пример вывода

```
[   45s] up:      430 | data:   0.92 GB | speed:  45.23 MB/s | ok: 430 | fail: 0 | quota: 1 | ⚠️ QUOTA: 23.9h
```

## Варианты обхода квоты

1. **Ротация `feature`** — разные типы дампов имеют разные квоты
2. **Ротация токенов** — если `sampleToken` можно генерировать
3. **Распределённая атака** — разные IP через прокси
4. **Ожидание** — скрипт делает это автоматически
